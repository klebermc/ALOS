# ALOS

Code placeholder for **"ALOS: Acoustic Localization System Applied to Indoor Navigation
of UAVs"** (ICCSPA 2019), by Kleber M. Cabral, Sérgio R. Barros dos Santos, Cairo L.
Nascimento Jr., and Sidney N. Givigi Jr., derived from Kleber's Master's work.

**Paper:** [doi:10.1109/ICCSPA.2019.8713689](https://doi.org/10.1109/ICCSPA.2019.8713689) ·
**Slides:** [presentation/ICCSPA2019_slides.pdf](presentation/ICCSPA2019_slides.pdf)

## What it does

Presents an indoor UAV localization system: an ultrasonic Acoustic Localization System
(ALOS) fused with IMU data via an Extended Kalman Filter, giving 3D position at 1 Hz.
Validated with a physical experiment (centimeter-level accuracy) and a multi-quadrotor
position-control simulation.
